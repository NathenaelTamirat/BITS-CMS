🔐 Security Design
• Access token: HS256 JWT, 15-min TTL, memory only
• Refresh token: HS256 JWT, 7-day TTL, httpOnly cookie
• Refresh tokens hashed (SHA-256) before DB storage
• Token rotation on every /refresh call
• bcrypt (12 rounds) for all passwords
• Rate limiter: 20 req/60s on /api/auth (in-memory buckets)
📡 CORS Policy
• Custom CORS middleware (not cors package)
• Respects CORS_ORIGIN env variable
• If CORS_ORIGIN=*, echoes request Origin
• Credentials: true always set
• Preflight OPTIONS → 204 No Content
• Vary: Origin header added for CDN safety
🧩 Role System
• Two roles: admin / superadmin
• Seeded superadmin via adminseed.ts script
• New UI-created accounts always role=admin
• requireRole('superadmin') guards: POST /admins,
  GET /admins, PATCH /admins/:id/*, PATCH /:id/deactivate
• authenticate guards all admin routes
🗃️ Media Architecture
• Media stored as BYTEA in PostgreSQL (no filesystem)
• Allowed: JPEG, PNG, GIF, WebP, MP4, PDF
• Max upload size: 10 MB (Multer + errorHandler)
• Served with Cache-Control: public, max-age=86400
• HTTP 206 Partial Content with Range header support
• YouTube: embed URL stored as mediaUrl (no file)
